ensembl.genes.annotation_qc.metrics.pairwise.splice¶

Source: src/python/ensembl/genes/annotation_qc/metrics/pairwise/splice.py

Splice-site and intron recovery along reference CDS structures (exploratory).

Tool-agnostic: works on the evaluated models of one comparison (one-based inclusive CDS segments of the transcripts the comparator selected). Nothing here reads annotation files or knows which predictor produced the models. Moved unchanged in definition from the dashboard branch (benchmark/splice.py); the runner supplies the inputs and writes splice_sites_by_position.tsv and cds_introns_by_length.tsv.

Definitions

CDS intron the gap between consecutive CDS segments of one transcript

(one-based inclusive); a single-segment CDS has none. UTR exons are never used.

donor/acceptor the 5’ / 3’ end of a CDS intron in the direction of

transcription; on the minus strand the donor is the intron’s higher coordinate. A splice site is identified by (sequence, strand, kind, intron-side coordinate).

support exact, same sequence and same strand. A reference intron is

recovered when an evaluated query transcript has the identical CDS intron; a donor (acceptor) is supported when an evaluated query transcript has a CDS intron with the same donor (acceptor). The query transcript need not belong to the prediction matched to the gene: this is the comparator’s unique-intron rule (intron_support) extended to single sites.

detected locus the comparator recovered the reference gene’s locus

(same-strand CDS overlap: cds_locus_recovered, i.e. at least one shared CDS base, unrounded). Sites of genes whose locus was not recovered are counted separately as missing-locus sites and are excluded from the recovery rates, so the rates describe structure at loci the predictor found.

Binned results need one reference transcript per gene (a policy whose reference selection is not “all”), so every gene contributes each of its introns once. Under “all” only the unique-intron totals are computed, deduplicated by sequence, strand and coordinates exactly as the comparator does.

Position along the reference CDS, in the direction of transcription (0 = first coding base, 1 = last coding base):

cds_span genomic distance from the coding start to the exon-intron junction,

over the genomic CDS span (introns included)

coding coding bases upstream of the junction over the CDS length

A donor junction lies after the last base of its upstream segment, an acceptor junction before the first base of its downstream segment, so both kinds always fall strictly inside (0, 1).
