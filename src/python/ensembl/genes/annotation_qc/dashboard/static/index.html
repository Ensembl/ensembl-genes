Each bar is one prediction run; segments are the comparator's per-gene CDS outcome counts (cds_outcome_* rows of metrics.tsv), which partition the evaluated reference genes R. Exact = coordinate-exact CDS in the gene's best CDS pair (not the one-to-one matching); ends ≠ and splice ≠ are partial agreement with the same or a different CDS intron chain; < 0.8 shares CDS with lower reciprocal overlap; span = locus found without CDS overlap.

Counts and denominators
How to read these columns

Loci recovered: a reference gene counts when an evaluated transcript of a same-strand prediction locus shares at least one coding base with it. It says the locus was found, not that the model is right.

One-to-one exact CDS recall / precision: reference and predicted genes that share an identical CDS (same start, every splice site and the same stop) are matched one-to-one (maximum matching; each gene used once). Recall = TP / R, precision = TP / Q.

One-to-one exact CDS F1 = 2 TP / (R + Q), on a 0–1 scale.

The per-gene coordinate-exact counts under “Counts and denominators” are a different measure (each gene's best CDS pair, before matching) and can exceed TP.

CDS intron chain: multi-segment reference genes whose CDS intron chain is identical in the best CDS pair, or in any transcript pair. Unique introns: (sequence, strand, start, end) sets, so their denominators grow with the number of evaluated isoforms. Split: a reference gene with ≥ 2 predicted counterparts; merge: a prediction with ≥ 2 reference counterparts (≥ 10 % shared CDS).
