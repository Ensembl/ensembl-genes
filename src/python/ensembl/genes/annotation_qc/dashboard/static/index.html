Prediction runs

Loci recovered is a permissive detection measure: a reference gene counts when a prediction on the same strand shares at least one coding base. It says the locus was found, not that the model is right.

Exact CDS recall and precision require identical CDS segment coordinates — the same start, every splice site and the same stop. Recall is the share of reference genes, precision the share of predicted genes, that are in a coordinate-exact pair.

F1 balances exact-model precision and recall (their harmonic mean, 2TP / (R + Q), on a 0–1 scale). Genes are matched one-to-one: the comparator's maximum matching uses each reference and each predicted gene at most once.
